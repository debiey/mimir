## ✨ Features

### 🖥️ Real-Time Monitoring
- Live dashboard with beautiful terminal UI
- CPU (per-core), Memory, Disk, Network monitoring
- Historical data with sparklines
- Top processes tracking

### 🩺 Health & Alerts
- Overall system health score (0-100)
- Configurable alert thresholds
- Desktop notifications
- Continuous monitoring mode

### 🔮 Predictive Analytics
- Predicts system issues before they happen
- Estimates time to CPU saturation
- OOM (Out of Memory) risk prediction
- Disk full forecasts

### 🛠️ Auto-Healing
- Automatically fixes common issues
- Memory cache clearing
- Disk space recovery
- Zombie process cleanup

### 💬 Natural Language
- Ask questions in plain English
- "why is my system slow?"
- "how much RAM do I have?"
- "is my disk full?"

## 🚀 Quick Install

```bash
curl -sSL https://raw.githubusercontent.com/debiey/mimir/main/install.sh | bash

# Start Mimir
mimir

# Inside the CLI:
status        - Show system status
dashboard     - Launch live dashboard
health        - Show health score
alerts        - Show active alerts
predict       - Show predictions
heal          - Auto-heal issues
ask           - Ask questions
help          - Show all commands


Requirements

    Python 3.8+

    Linux (Ubuntu, Debian, Fedora, Arch, etc.) or macOS
